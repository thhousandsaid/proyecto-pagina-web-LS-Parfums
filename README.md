#  Página Web Sencilla | Simple Web Page

##  Español

### Descripción
Este proyecto consiste en una página web sencilla e interactiva desarrollada utilizando únicamente **HTML5** y **CSS3**. Su propósito es demostrar la estructura básica de una página web con un diseño limpio y fácil de entender.

### Características
- Diseño moderno y sencillo.
- Interfaz amigable para el usuario.
- Estructura organizada con HTML5.
- Estilos personalizados con CSS3.
- Diseño adaptable (Responsive) para diferentes dispositivos.
- Fácil de modificar y personalizar.

### Tecnologías Utilizadas
- HTML5
- CSS3

### Estructura del Proyecto
```
proyecto/
│── index.html
│── style.css
└── README.md
```

### Cómo utilizar el proyecto
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador web.
3. ¡Listo! Ya puedes visualizar la página.

### Objetivo
Este proyecto está pensado como ejemplo para estudiantes o personas que están aprendiendo desarrollo web con HTML y CSS.

#  English

## Description
This project is a simple interactive web page built using only **HTML5** and **CSS3**. Its purpose is to demonstrate the basic structure of a website with a clean and easy-to-understand design.

## Features
- Simple and modern design.
- User-friendly interface.
- Well-organized HTML5 structure.
- Custom styling with CSS3.
- Responsive layout for different screen sizes.
- Easy to customize and expand.

## Technologies Used
- HTML5
- CSS3

## Project Structure
```
project/
│── index.html
│── style.css
└── README.md
```

## How to Use
1. Download or clone this repository.
2. Open the `index.html` file in your preferred web browser.
3. That's it! You can now explore the web page.

## Purpose
This project is intended as a learning example for beginners who are starting their journey in web development using HTML and CSS.
